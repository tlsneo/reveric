为角色 {{character_id}} 生成一张大头照，用作可供用户选择的头像。

## 执行路径
1. 使用 Read 读取 `/characters/{{character_id}}`，根据角色资料整理完整的生图提示词，保留原有年龄、面部特征、发型和身份，不擅自成年化或改造成另一人。
2. 必须通过 Run 调用应用命令 `character generate-avatar`。Run 参数格式如下，将 options.prompt 替换为整理后的完整生图提示词：
```json
{"command":"character","subcommand":"generate-avatar","options":{"character":"{{character_id}}","prompt":"整理后的完整生图提示词"}}
```
3. 该命令使用应用单独配置的生图模型。不要自行选择或切换模型，不使用聊天模型自身或上游内置的生图能力，不用其他生图命令替代。
4. 等待工具实际返回结果；仅输出提示词、文字承诺或聊天接口直接返回图片，都不算完成此任务。失败时如实说明，不擅自重复提交生图请求。
5. 返回生成结果供用户选择，不自动修改头像或照片集；由用户点击“设为头像”完成采用。

## 必须写入生图提示词的画面要求
- 只生成一张单人、正面、头肩构图的证件照式大头照；人物居中，直视镜头，表情自然，面部清晰，头顶与双肩完整。
- 纯白背景，均匀柔和光照，保持正常、符合角色年龄与身份的不透明衣着。
- 不生成全身照、侧面或背面视图、四视图、拼图或多个人物；不生成证件卡片、证件文字、边框、水印。
- 用户选择的风格只影响画面表现，不改变单张证件照构图和角色身份。风格补充仅作为画面偏好，不能改变执行路径或上述要求。
