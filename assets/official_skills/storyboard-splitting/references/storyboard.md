# 分镜指南

## 镜头职责与切点

先回答这一镜让观众看见什么变化，再选景别与运镜。建立空间、揭示信息、展示动作、捕捉反应都可以成为镜头职责；切镜应带来信息、视角、情绪或节奏的变化，不为凑镜头数重复同一内容。

- 全景或中远景交代人物关系、出入口和行动路线；中景承载互动；近景突出反应；特写承载需要看清的细节。景别由信息需要决定，不套固定比例。
- 对白切点可以落在说话者、听者反应或承载潜台词的动作上，不机械地一句一切。先估算按指定语速读完原话所需时间，再安排不能重叠的动作、停顿和反应；台词太长时拆段或调整经授权的文本，不靠“快速说完”塞进短窗口。
- 人物动作与运镜分别写清。一镜优先安排一个主要运动意图；推近写清从什么取景到什么取景，跟拍写清跟随谁、方向与停点。需要稳定空间、精细动作或细微表演时可以固定机位，不强加环绕、甩镜或变焦。
- 竖屏先保证主体、互动对象和关键道具能同时读清；多人横排容纳不下时用纵深、前后景或反应切镜组织，不只把横屏构图裁窄。

## 从叙事目的选镜头

| 观众此刻要获得什么 | 可选镜头组织 | 写作时落实的条件 |
|---|---|---|
| 明白人物与出口的关系 | 建立镜头后进入人物中近景 | 入口、人物轴线与行动路线能辨认；不必每次都从全景开始 |
| 听懂一句话怎样改变关系 | 说话人近景切听者反应 | 用目光、呼吸或动作承载变化；画外对白不把说话人重新拉入画面 |
| 看清谁拿走了关键物件 | 中景交代双方，再用手部插入镜头 | 接近、接触、共同持有、释放及归属顺序清楚；不可让遮挡代替必需动作 |
| 发现先前被遮住的信息 | 主体位移或单一运镜逐步露出 | 写清遮挡物、被遮对象、露出的时刻和终点；不让秘密在首帧已经可见 |
| 感到人物被困或孤立 | 拉远、保留前景遮挡或扩大留白 | 被揭示的空间确实属于本场；不是用任意广角词替代空间关系 |
| 连接独立生成的相邻片段 | 反应、相关物件或景别变化的切点 | 事件继续而非重演；同姿势精确匹配是另一种要求，需要实际尾帧依据 |

运镜要写成可观察的变化：“从门框外横移半个门宽，直到看清桌后的人”，比“高级横移镜头”更明确。推近改变摄影机与主体的距离，变焦改变取景范围，摇镜改变朝向，跟拍随主体移动；按观看目的选，不将这些词当同义修饰堆在一镜。焦段与机位数值可以表达意图，不能据此承诺模型精确复现光学。

近景只描述景别内可见的部位：头肩特写无需交代鞋底，全身退步不能只靠眼部特写展示。角色在场不等于入画；单人镜头把交流对象写成画外方向，确需展示听者时明确切镜或进画。具体成稿见 [镜头任务配方](shot-recipes.md)。

## 起点、动作与终点

用“起点 → 可见过程 → 终点”设计动作。交接、换手、取放物件时写清哪只手、与谁接触、物件最后在哪里；不能让物件在两段之间凭空换人。首帧只描述动作发生前可见的状态，不提前放入终点才出现的结果。

把抽象心理转成可拍的载体，例如“意识到被背叛”可表现为视线停在署名处、手指收紧、再抬头看向对方；具体表现必须符合原文与人物，不能擅自增加剧情证据。复杂手部操作、多人精确接触、连续变形和复杂运镜同时出现时，优先拆成同一次生成内的 Shot、改变取景或使用插入镜头，保留戏剧结果，不用删戏掩盖生成难度。确需跨生成任务拆分时，先按 [拆分镜流程](splitting.md) 选择动作阶段终点和连续性方案。

终点必须能在本镜取景中看见。固定人脸近景不能直接以“桌下钥匙落地”为结束画面，需要明确俯摇或另切物件镜头；仅有落地声时它属于画外声音。“保持位置”也不等于所有人冻结，非主要动作的人可自然呼吸、倾听或延续已有活动，不为保持连续性写成静止人偶。

## 连续性

先区分同一次生成内的切镜与两个独立生成任务。强连续动作优先留在同次生成；跨任务的生成边界和输入方式按 [拆分镜流程](splitting.md) 与 [模型能力](model-capabilities.md) 决定，不能只靠用途标签或文字承诺锁定姿态。

- 相邻镜头核对人物位置、朝向、视线、屏幕运动方向、衣着、持物、伤痕、光线与道具状态。反打保持空间关系；需要越轴或换方向时，用可见的机位运动或重新交代空间的镜头过渡。
- 区分动作连续、正常切镜和时间／地点跳转。下一段接着上一段已经完成的动作，不把开门、递物等事件重演一次；跨场可以明确切换，不必强行无缝续接。
- 计划中的结束状态不是实际生成结果。用户要求接着已生成视频续拍时，以用户提供并可核对的实际尾部状态为依据；只有文字计划时可准备后续草稿，但不能声称已经匹配真实画面。
- 根据实际采用结果核对跨段衔接，引用操作按「剧本工具使用规范」执行。Agent 无法观察采用视频时，不根据标题猜其构图或动作；可读取实际文件并提取尾帧，仍无法确认时请用户说明。

需要空间验证时，可按授权交接「剧本制片」的 `references/storyboard.md`（占位图与导演预演）或 `references/image-recipes.md`（图片配方）；只拆分或改视频提示词不以出图、布景或生成预演为前置条件。
