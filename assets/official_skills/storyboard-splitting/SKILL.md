# AI 拆分镜

将既有剧本中的动作、逐字对白和戏剧变化落实为本次需要的分镜与完整视频提示词。本技能拥有完整拆分与视频提示词创作方法，不依赖加载「剧本制片」。界面每条视频“分镜”对应可独立生成的场内制作条目，一条可以包含多个 Shot 镜头；换景别不等于新建分镜，镜头不另建资源。

## 进入任务

先读取目标场次完整正文、真实角色与地点，以及当前集已有分镜，不能拿场次梗概代替正文。按当前实际稿件确定范围，已有同内容条目在授权范围内修订，不重复新增；局部修改不重做整集。用户直接提供原文且只要文字草案时，可据此设计，说明外观、输入与模型的未确认条件；实际写入前再核对应用资源。

拆分或修订分镜按“原文事项与戏剧变化 → 镜头与表演预算 → 独立生成分组 → 目标格式 → 逐镜及跨片段核对 → 保存回读”交付，完整步骤见 [拆分镜流程](references/splitting.md)。先理解整场，再设计可见变化与完整表演窗口，最后决定哪些镜头同次生成。约 5 秒是显存预算下的软偏好，内容可短可长，必要延长须说明负载，不加速、删戏或凑空镜；不可逆动作只在归属镜头执行一次，相邻镜头承接后态。简明预算、动作归属和分组理由放在 prompt 外，不另建资源。

## 写入与交付边界

- 读写应用剧本、分镜、配置或输入前，加载「剧本工具使用规范」对应附件（分镜与媒体节点为 `references/clips.md`）；操作路径、字段、JSON、引用与执行契约由它维护，不在本技能复制。
- 按授权保存与回读，保留已有 ID、原剧本文本、真实引用和未改内容；只写草稿不自动生成、绑定、采用或导出媒体。不把缺图变成必须先出图的副作用。
- 逐 Shot 检查原文事项、逐字对白、动作唯一归属、画内起止、声音窗口和切点，再检查相邻分组是否该合并、是否重演、状态是否接得上；对白子串存在或总时长达标不能替代这些核对。整集计划时长回读与证据边界见拆分镜流程。
- 需要正文改写时交接「剧本写作」并取得相应授权；需要视觉素材或占位／导演预演时，可按需交接「剧本制片」的 `references/image-references.md`、`references/image-recipes.md` 或 `references/storyboard.md`，已授权生成与实际结果返修使用其 `references/production.md`、`references/troubleshooting.md`。不要求先完整加载其他专业技能，不把这些环节作为拆分前置条件。
- 配方与案例是教学假设，不补成作品事实。给出完整可用正文，不以原则、空模板或待填清单代替成稿；区分“已保存”“参考待绑定”“待生成”“实际结果已核对”，未观察媒体不声称成片已验证。
- 尊重官方技能的停用、删除、同名本地覆盖与自定义选择；所需技能不可用时说明缺口，不偷偷回退旧制片方法或源码内容。
