# 原文分析与材料诊断

先读实际材料，再决定如何整理。材料的称呼只是入口，不是必须由用户先填写的分类：模型应从文本信号判断小说叙述、梗概、对白、已有剧本以及混合或残缺部分，并让判断改变后续动作。

## 按材料与范围读取

- 小说或连续叙述：精读用户给出的范围，把心理、概述和时间跳跃拆成可见行动、声音及必要的场间连接；摘要只能导航，不能代替正文来源。
- 梗概：提取已确认事件、因果和人物意图，再标出需要创作的现场过程；不得把扩写细节冒充原文事实。
- 已有剧本：读取完整相关场次元素和必要相邻内容，保留有效结构、对白与动作，不用旧梗概替代正文。
- 纯对白或混合草稿：按段落局部判断；没有可靠依据时保留说话人未知、场次边界或待核信息，不乱配角色、不把残句补成确定事实。

短篇或用户点名的章节直接精读。长篇先看目录、简介及已有摘要以确定结构，再读取关键选择、关系转折和结局所在原文；摘要用于导航，不能充当逐句改写的来源。长材料按真实范围分批，每批只保留必要交接：已读位置、关键事件、人物/地点/道具变化、未解决问题、覆盖缺口和下一批起点；短任务无需为每个段落建立表格。

## 事件与证据

优先记录一旦删改就会影响主线、人物选择或信息释放的片段：

| 项目 | 要回答的问题 |
|---|---|
| 来源与范围 | 在本次材料哪一段，已读还是待补？ |
| 行动与目的 | 谁为了什么做了什么？ |
| 反制与结果 | 什么让计划失效，哪个信息、关系、资源或机会改变？ |
| 依赖与后果 | 需要哪项前置事实，又支撑哪个后续事件？ |
| 观看体验与信息 | 角色知道什么，观众何时知道什么，在此理解、期待、担忧或重新判断什么？ |

不需要给每段文字套表。把关键事件映射到计划场次和已写元素，之后检查是否遗漏、重复或顺序错误；尚未写入的事件仍是来源材料，不是当前剧本事实。

## 先按因果聚合，再讨论分集

小说可能分三章写一次谈判，也可能在一章里跨过数月。按一个目标的展开与结果聚合事件，找出自然的局部结果和下一步压力；之后才按目标集长调整。用户只要求整理局部场次时，不因缺少集数或时长而停止。

## 资料核对

人物、地点和道具先查名称、别名、身份及已有记录再复用或创建。同名不自动合人；重复出场不重复建档；同一地点不同场次或时段不当成新地点。道具只追踪承担证据、交换、身份、危险或关系作用的物件，保留已有头像、四视图、照片和有效资料，不凭空补人物外貌、道具属性或地点布局；未说明的信息保留未知。同一人兼有目击、误导和揭示功能时，核对其知情范围是否成立。

抽样或局部分析只给局部结论，明确未覆盖部分。重大删改、合人、结局变化和未知信息沿用既有授权规则；不要以列表或旧状态宣称读过完整正文。

## 快评应当能被反驳

以材料中的具体选择、关系和场面说明改编潜力，也指出障碍：关键变化只存在于内心、长线回报依赖大量铺垫、人物过多但各有必要功能、核心戏难以在目标时长内成立。“适合改编”的结论至少说清打算保留什么、压缩什么、哪个缺口仍要补读。不要使用未经验证的播放量、付费转化率或市场保证。
