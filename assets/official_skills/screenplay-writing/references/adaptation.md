# 剧本改编与材料整理

改编要保住作者想让观众经历的选择、代价与情感回报。原著章节与剧集不必一一对应，改编方案也不等于缩短后的剧情摘要；用户直接贴来的材料不论是小说段落、梗概、对白、已有剧本还是混合草稿，都先判断其性质和完整程度，再决定保留、转化、补写或暂缓；不把所有输入一律重写成同一种格式。

## 从实际材料进入

- 读取本次真实材料及必要的当前剧本上下文。没有来源绑定、类型选择或完整原作前置要求；只有用户给出的片段时，结论和整理范围就以该片段为边界。
- 区分不能改的核心事实、可探索部分和已授权的改编幅度。沿用用户已接受的方案，不重做选型；改变主角、结局、核心关系或忠实程度前，说明差异与影响并取得确认。已给出的集数、时长和制作方式直接使用，价值快评不必先问齐制作参数。只有书名时不能凭记忆宣称完成原著分析。
- 小说叙述转为可见行动和可听声音；已有剧本保留有效场次、动作和对白，只修正确有问题的部分；梗概扩展时区分原文事实与为落戏补充的创作；纯对白不凭空给台词配说话人，混合材料按局部性质处理。
- 缺少关键事实、材料截断或非叙事内容不足以成场时，说明限制并保留待补位置；长材料分批处理，记录已读范围、未覆盖事件和下一批起点，不宣称未读内容已完成。

## 工作方式

1. **诊断与找戏**：识别谁追求什么、遭到什么阻力、作出什么选择、付出什么代价，以及观众何时知道关键事实。原文分析和覆盖记录见 [原文分析](source-analysis.md)。
2. **对账与取舍**：按别名、身份和实际功能查找并复用人物、地点和关键道具；同名不自动合并，重复出场不重复建档。给出保留、删减、合并、重排与必要连接，每项重大取舍能指回材料位置，并说明失去的功能由谁承担。人物和场所归并、心理描写外化见 [改编决策](adaptation-decisions.md)。
3. **写前检验因果**：被挪前的揭示是否提前泄密？合并人物是否拥有相应经历和信息？删掉的段落是否带走后续行动的原因？先核对材料证据再落稿，未知的外貌、布局、说话人和动机不伪装成原文事实，影响核心剧情的缺口不擅自补造。
4. **交付本次范围**：价值评估给出建议、依据和材料缺口；改编方案给出故事核心、主要取舍、人物与事件对应关系、建议结构及制作难点。要整理场次时读取 [自然分场](episode-planning.md) 的“整理材料时的分场”，不因此启动分集设计；要求正文时，再按 [场次写作](scene-writing.md) 把已明确且获准的范围写成真实结构化正文。
5. **写后回读**：读回实际写入范围及必要相邻正文，核对来源关键事件去向、遗漏与重复、顺序、对白归属、人物知情/位置/持物衔接和资源引用，区分资料已提取、场次已规划、正文已写入、依赖待补和本批未完成。事实与关系维护由调用方按主 Agent 既有流程安排，遵守用户不委派或限制自动整理的要求，不另造流水线。

## 交接与边界

- 输出中分清原文事实、推断和改编新增。未获采用的候选不写成既定故事事实。
- 需要保存到剧本工作区时，先加载「剧本工具使用规范」。讨论或预览不写入；明确保存规划时可写入已有集大纲、节拍或场次梗概，但不因规划默认创建正文或资料实体。分析来源与写入目标分别定位，不覆盖原作或把来源 ID 当作目标身份。正式整理时使用真实人物、地点与节拍引用，关键道具形成可查询的 `items` 资料并按已有正文/证据契约记录，不发明场次道具字段；必要资料只有在任务授权的范围内补齐。
- 不强制砍掉固定数量的角色、把所有题材改成爽剧，或用宣传性的商业判断代替材料分析；不得强制爽点、钩子、冲突配额或角色数量，不按固定秒数机械切场，也不启动出图、配音或视频生成；制作难点作为取舍依据交给作者。
