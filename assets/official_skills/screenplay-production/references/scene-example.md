# 从原文到制作交付：车站失物处

本附件是一份原创完整教学案例，展示同一场戏怎样经过覆盖核对、图片准备、分镜编排、提示词和结果验收。所有时长、人物外观与美术设定都是示例假设，不代表用户项目或已验证模型能力；没有生成图片或视频。

## 一、先确定原文与视觉事实

原文：

> 雨夜。失物处柜台，林岚在外侧，值班员在内侧。柜台上放着一只合着盖的蓝色铁盒。  
> 林岚：“蓝盒子，是我父亲留下的。”  
> 值班员把手压在盒盖上：“里面有什么？”  
> 林岚：“一枚断齿的钥匙。”  
> 值班员移开手，推过铁盒。林岚接住，打开盒盖。盒内是一枚断齿钥匙。  
> 林岚停住，抬眼看他。值班员：“他让我等你。”  
> 林岚合上盒盖，双手把盒子抱在身前。

为写出独立可读的示例，另假设已确认以下视觉设定：林岚约三十岁，齐下颌黑短发，深灰夹克；值班员约五十岁，短灰发、方脸，藏蓝工作外套。蓝色铁盒无锁扣，长边约两个手掌宽，铰链在靠值班员一侧，内衬灰布，内有一枚黄铜钥匙，钥匙齿列中间缺一齿。铁盒和钥匙没有需要读出的文字。

柜台沿东西方向，林岚站南侧、值班员站北侧；摄影机保持在两人连线的东侧，使林岚在双人镜头中偏左、值班员偏右。柜台北面是失物架，南侧有入口，西墙高窗透入微弱冷光，柜台上方暖白灯提供主光。窗口雨声低而连续。示例采用横幅；最终比例仍以配置为准。

原文确定事件和台词，视觉设定确定身份、物件结构与空间。摄影机的取景选择不能把钥匙提前露给观众，不能把“抱盒”提前到“接盒”之前。

## 二、先设计镜头与表演，再按预算分组

本场先由原话确认盒内之物，再交接并验证钥匙，最后一句改变林岚对来历的理解。先拍这条变化，不先套三个等长容器：来历用双人中景交代柜台关系；压盖发问用能同时看见脸、手和盒盖的中近景；回答回到林岚。交接保留双方手部与整段台面，开盖改用略俯的手部近景，看清钥匙而不再演开盖。最后回双人中景，同时容纳抬眼、回答、合盖和抱盒，不为每个动作额外切一镜。

以下是文本估计，不是试读或音频实测；依据本例无锁扣的小盒、短距离台面交接和自然清楚的普通话估算，不套固定字速或统一动作秒数。开场辨位只在 A 计一次，C 的停住抬眼才是人物反应，B 的末段用于观众辨认缺齿，不再各加一份反应停顿。本例对白轮流说，合盖在最后一句说完后，均按顺序相加；B 推送与接住的接触阶段真正同时发生，已经包含在同一交接窗口，不把双方用时重复相加。

假设目标渠道接受 5、6、8 秒整秒时长，仅用于文字草稿；未查询真实配置，没有配置供应商或型号，未按输出 fps／帧数校准。这些值不是新的默认或实测保证；实际试读、预演或合法时长不同，应重算窗口与分组，不赶表演、不删原话，也不为凑五秒加凝视或空动作。

| 分镜 | 计划 duration_ms | 表演预算（文本估计，秒） | 合计（秒） | 分组／边界理由 |
|---|---|---|---|---|
| A | 8000 | 0.4 开场辨位 + 3.2 来历原话 + 0.5 压盖 + 1.4 发问 + 2.1 回答 + 0.4 等候回应 | 8.0 | 三句构成完整确认，内部切点为 3.6 与 5.5 秒；不能把三轮发声及压盖赶进五秒。到答完并等待回应才结束，下一段进入交接，不按三句建三次生成。 |
| B | 6000 | 0.7 移掌至盒侧 + 2.3 推送接稳并松手 + 1.7 移指开盖并离开盖沿 + 1.3 看清钥匙缺齿 | 6.0 | 交接与开盖是同一连续物件过程，在 3.0 秒接稳后只切取景；不能为五秒赶复杂手部接触或省略缺齿阅读。揭示完成后才可独立进入人物反应。 |
| C | 5000 | 0.7 停住抬眼 + 1.5 最后一句 + 1.1 合盖 + 1.7 双手抬起抱盒 | 5.0 | 短句与无锁扣盒的简单收束可在同一中景内自然完成，结束于抱到身前；不是延长抱盒停留凑数，也不把这四件事拆成四次生成。 |

分组后再核对“前态 → 唯一执行 Shot → 后态”；下面的归属只是编排说明，不写进 H3 正文，不创建新资源：

| 原文事项 | 分镜与 Shot | 前态、执行与后态 |
|---|---|---|
| 林岚说明蓝盒来历 | A / Shot 1 | 盒盖闭合、尚无人压盖；原话一次，盒仍在值班员一侧 |
| 值班员压盖发问 | A / Shot 2 | 手尚未压盖 → 右掌压盖后发问 → 右掌留在闭合盖上 |
| 林岚回答断齿钥匙 | A / Shot 3 | 压盖状态承接；只回答，不开盒，钥匙不可见 |
| 移手、推盒、接住 | B / Shot 1 | 右掌已压盖 → 移掌、推送与双手接稳、值班员松手 → 闭盒在林岚面前台上 |
| 开盖、看清钥匙 | B / Shot 2 | 盒已接稳仍闭合 → 林岚开盖一次 → 盖近直立，钥匙缺齿可辨，留在灰布上 |
| 林岚停住抬眼、值班员回答 | C / Shot 1 | 盒已打开 → 林岚停住抬眼后最后一句一次 → 才开始合盖 |
| 合盖、双手抱盒 | C / Shot 1 | 盒仍打开 → 合盖一次再抬起 → 林岚双手抱闭盒，钥匙仍在盒内 |

相邻组也要问是否无谓切碎：A 与 B 以完整问答后的交接起点相连，合并会将本可在问答结束处分开的内容变成更长的单次生成，增加显存预算；B 与 C 以缺齿揭示后的反应入口相连，合并也无必要，不能把阅读时间或抬眼反应在两段各演一次。三个独立单元仍须核对实际接缝，文字不能锁定同一帧姿态。不是因为有三个段落就必须建三个分镜，也不是所有场景都应使用这组秒数或镜头数。

播放顺序是 A → B → C。制作时可先准备共同人物、柜台和铁盒，再验证动作负载最高的 B；C 的开场最终对照 B 的实际采用结果。若 B 没有完整开盖，先修 B 或明确如何补完，不能让 C 从不存在的状态开始。

## 三、图片准备

资产计划不是实际绑定。复用已有的合格人物图和空间图；只有缺失或本场确需新状态时才制作。建议准备两个人物参考、一个柜台空间参考、同一铁盒的闭合与打开状态；钥匙细节在打开图仍看不清时再单独补图。A/B/C 是本文分镜简称，不是应用资源 ID。

### 柜台空场提示词

```text
雨夜的车站失物处，横向木柜台沿东西方向，南侧为访客区，北侧为值班区与失物架。摄影机位于柜台东侧，画面左侧留出南侧访客站位，右侧留出北侧值班员站位，台面横向连接双方。
北面失物架、西墙高窗与南侧入口保持明确空间关系。高窗透入微弱冷色夜光，柜台上方暖白灯照亮木台面。环境朴素、可辨认，画面无人，柜台上暂不摆蓝色铁盒，不生成标注、图例或新招牌文字。
```

### 蓝色铁盒的闭合与打开状态

```text
单个蓝色长方形铁盒的闭合参考图。长边约两个手掌宽，深蓝漆面略有使用磨痕，结构完整；没有锁扣，盒盖与盒身接缝清楚，铰链连接在后侧长边。四分之三角度能看清顶面、前沿与侧面。盒盖闭合，内部完全不可见。
置于中性浅灰背景，柔光照清结构与漆面，无人、无手，不出现标签文字或第二个盒子。
```

```text
已提供蓝色铁盒参考的打开状态，保持同一尺寸、磨痕、铰链与机位。盒盖沿后侧长边铰链向后打开，接近直立，盒体不旋转、不换边。灰布内衬上只有一枚黄铜钥匙，钥匙齿列中间缺一齿，齿边无遮挡、可辨认。
柔光照清盒内与钥匙轮廓，无手进入、不增加其他物件、锁扣或文字，不把钥匙放到盖子上。
```

### B 的首帧提示词

下例假设相应人物、柜台和闭盒图片已实际提供并核对：

```text
失物处柜台双人中景，机位在两人连线东侧，林岚在画面左侧的柜台外，值班员在右侧柜台内。沿用对应人物参考的面貌与服装、柜台参考的布局和暖白顶灯，西墙高窗的冷色夜光不变。
闭合蓝色铁盒仍在值班员一侧的台面，他的右掌压在盒盖中央。林岚双手停在自己一侧柜台边缘，尚未接触铁盒。盒盖铰链朝值班员方向，钥匙不可见；保留两人之间可推送铁盒的完整台面，不提前画成林岚已经拿到盒子。
```

若采用首尾帧，B 的目标尾帧应为盒子已在林岚一侧、盒盖打开、钥匙留在内衬上，林岚未取出钥匙。目标图只提供终点，不能替代视频中可见的推送与开盖。

## 四、三个分镜的完整 H3 中文草稿

结构遵循 [MiniMax H3 提示词](minimax-h3-prompts.md) 的原字段与切点语法。以下没有实际绑定输入，明确选择无参考 T2VA 三字段作文字教学草稿；上节图片准备是另一环节的条件假设，不意味着这些视频已绑定图。各段独立可读，时间各自从零开始，配置计划值见上表，估计与分组理由不混入 prompt。

若实际任务明确要全参考，仍须保持该目标并报告“参考待绑定”，不能拿这里的 T2VA 当作全参考最终稿；真实输入读取并绑定后，按 H3 附件改用对应模式与真实引用。这里不放虚构 ref、身份参考占位符或伪造首帧对齐句，也不承诺精确帧、姿态、文字或显存占用。

## 五、结果验收与交付

下列检查针对实际生成视频；本案例没有媒体，只能验证文字编排、预算相加与动作归属，不能证明实际表演、模型遵循或视频质量。若只能看静帧，动作顺序、台词、声音和口型仍待检查。

| 检查对象 | 可以定位的通过条件 |
|---|---|
| 原文覆盖 | 四句对白按原顺序各出现一次，未增加回答或旁白 |
| 信息揭示 | A 中钥匙未出现；B 先开盖再展示缺齿，缺齿确实能辨认 |
| 持有与状态 | 只推送一次；接住后再开盖，钥匙不出盒；C 合盖后才抱起 |
| 空间与身份 | 柜台两侧未互换，铁盒铰链不换边，机位反打仍在同一轴线侧 |
| 声音 | 推送为摩擦声，开盖为铰链声，合盖为轻响；没有暗示砸盒的巨响 |
| 段间连接 | A 到 B 仍是压盖状态；B 到 C 盒已打开、钥匙仍在；连接处雨声不突跳 |

若实际 B 结束时盒子只推到台面中间，不能在 C 直接写“林岚已经抱住”。保留符合要求的部分，定位 B 的推送、接触或时间问题，按 [结果诊断](troubleshooting.md) 修正后再核对衔接。
