# 剧本制片

将已确认的剧本与分镜方案落实为视觉资产、空间预演及经授权的生成结果。分镜与视频提示词创作交「AI 拆分镜」，剧本正文改写交「剧本写作」；仅在任务需要对应环节时交接，不要求先完整加载其他专业技能。

## 进入任务

读写剧本与分镜、读取制作设置或执行生成前，加载「剧本工具使用规范」对应附件；制作画布和导演台操作也由该技能负责。它维护路径、字段、素材引用和执行契约，本技能负责视觉素材与制作方法。独立文件加工和多轨剪辑使用「媒体处理与剪辑」。

先定位本次范围的实际剧本、已有分镜和素材，只改一段时不重做整集。以原剧情、逐字对白、角色身份和关键道具状态为依据，不把梗概或旧草稿当成当前正文。只要图片提示词或文字方案时，不自动生成或伪造素材引用；缺失条件留在交付说明中。

配方是可迁移的写法，不是固定剧情或参数。使用已读取的真实人物、道具、空间与本次授权，说明草案假设，不把教学例子的设定补成作品事实。需要成稿时给完整图片提示词，不只返回原则或空模板。

制片人物参考必须是一张横向组合图：左侧大幅头肩肖像，右侧依次为同一人物、同一造型的正面、侧面、背面全身图；布局与验收见 [图片资产与参考](references/image-references.md)。单张正面图不能作为已完成的人物参考交付，三视图也不是仅在审核时才做的可选展示。

先检查人物设定与已有图片：已有符合格式和当前造型的参考图直接复用；只有头像、正面图或分开的多角度图时，沿用已有脸和造型，仅补齐缺失视图或整理排版。没有可用参考时才新制组合图，不强制先生成单幅选角图。已有角色但缺少三视图时，可以询问用户是否需要正面图选角；仅在用户选择后执行，不自动增加该步骤。生成和补图仍以本次授权为准，只讨论或改提示词时列出缺口，不自动生成。检查实际提交会叠加的风格，避免全剧的工业、灰暗或破旧氛围改写角色的阶层与衣料。

## 写入与交付

- 图片节点使用能辨认对象和用途的标题，例如“江小白｜人物三视图”“镇北侯府正厅｜场景”“第1场·踹飞撞柱｜占位·起始站位”。标题写入现有图片片段的 `title`，不画进图片；沿用真实片段、节点和采用资产 ID 定位结果，不假定标题会自动成为资产名称或文件名。占位图按当前分镜与动作起点制作，不先查找、读图筛选旧占位图以求复用。
- 需要写入时保留已有资源 ID 和未改内容。片段提示词与剧本正文分别维护，不假定两者自动同步。只修改镜头表达时不擅自改写剧情；确需调整原文时按用户授权处理。
- 按用户授权执行分镜编辑、参考绑定、生成、采用或导出，不把“写提示词”自动扩大成生成任务。先确认真实素材和模型能力，缺少条件时列明缺口；各操作的参数与限制遵循对应内置技能，不自行编造。
- 新增或重新绑定参考时，人物、场景等图片已有当前画布的来源节点，就优先连接该节点；没有对应节点或用户明确要求固定历史图片时才直接引用资产。按「剧本工具使用规范」的分镜与媒体节点附件定位来源并核对连线，仅修改提示词时不转换原有引用。
- 完成后回读本次实际写入，核对视觉资产、配置、真实 ref 及受影响的下游输入；检查实际生成结果，未通过时定点返修或说明缺口，不报成片完成。
- 区分“片段已保存”“参考待绑定”“待生成”和“实际结果已核对”，不以提示词完成代替视频完成。
